# ARS Suite punch list

Started from the 2026-11-17 review. One line per item; ★ = check before the next contest you enter.
Sections: **1** Completed · **2** Completed, needs testing · **3** Known bugs · **4** Needs coding · **5** Future.

**IDs.** Every item has a permanent ID: its section and a number (`2a-3`, `3-2`, `4b-1`). An ID never changes. When an item is
finished it moves to section 1 **keeping its ID**, and the gap it leaves is not refilled, so "2a-3 is done" always means the same
item. New items take the next unused number in their section.
