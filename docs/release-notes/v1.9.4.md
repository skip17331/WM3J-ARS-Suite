## WM3J ARS Suite v1.9.4

J-Bridge decodes now show where the station is, and J-Digi stops flooding the console.

### New
- **J-Bridge shows country and distance.** Each WSJT-X / JTDX decode row now ends with the DX station's country and its
  distance from you, as the screen was always designed to show. Before, those were blank: only the retired hub ever
  filled them in. The app now works them out itself from the callsign, using the suite's DXCC prefix data:
  - the **country** and continent;
  - the **distance and bearing** from your station. If the message ends in a four-character grid (for example
    `CQ DL1ABC JO31`) that grid is used; otherwise the middle of the country, which can be well off for large countries
    such as the US, Russia or Brazil;
  - the **callsign, dial frequency, mode and band**, taken from the message and the latest WSJT-X status.

  Your own position comes from **J-Hub ▸ Station** (latitude and longitude, or else the grid square). If neither is set,
  the country still shows but distance is left out.

### Fixed
- **J-Digi no longer floods the console.** The CW, RTTY, PSK31 and Olivia decoders had their debug switches left on and
  printed a line for every bit or frame — about 600 lines in 25 seconds on the default RTTY mode. They are off now.

### Housekeeping
- **J-Bridge is a thin library.** It dropped the JavaFX, WebSocket, JSON and logging libraries that belonged to the old
  standalone app, and shrank from a multi-megabyte jar to about 20 KB. The app itself is unchanged: its jar has the
  same contents as before.
- The J-Bridge code and notes no longer describe the retired hub's message format.
