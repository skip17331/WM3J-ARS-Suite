## WM3J ARS Suite v1.12.1

Callsign lookups use your QRZ account again, clicking a DX spot now works the same everywhere you can log, and the
DX cluster no longer stays connected after you close the program. J-Hub's setup pages are now one screen with a menu.

### Fixed
- **Callsign lookup now asks your own callbook account first.** The free Callook lookup was tried first and answered
  almost every US callsign, so your QRZ.com, HamQTH, QRZCQ or HamCall login was never used and no county came back.
  Callook is now the last one tried, as a fallback. QRZ also logs in again by itself when it says the session key is no
  longer valid; before, it only did that on a timeout and could stay stuck until you restarted the program.
- **Clicking a DX spot starts a fresh contact in every log form.** A spot click now clears the form, enters the
  callsign and looks it up, in **J-Log** and in **J-Log-Quick** on the J-Hub dashboard. J-Log-Quick had no lookup at all
  and ignored spot clicks made on the dashboard. Before, a second spot only filled the fields that were still empty, so
  the previous station's name, grid and QTH stayed and blocked the new answer. Clicking the same spot again looks it up
  again, and a slow reply for an earlier spot can no longer fill in the next one. (The J-Map QSO card already worked this
  way; the contest form still only takes the callsign, band and mode, because it has no callbook lookup.)
- **The DX cluster and RBN disconnect when you close the program.** The connection belongs to the background hub, and
  a hub started on its own (`ars-fx --hub`, or from the tray) kept it open after every window was gone. Now, when the
  last window closes, the hub waits 8 seconds (the `hub.lingerSeconds` setting) and then hangs up. It does not reconnect
  by itself: press **Connect** when you want spots again. A hub the program started for itself still exits at that point,
  and now also hangs up cleanly first. A hub started on its own with no window ever opened hangs up after 30 seconds.
- **Only one hub can run.** Two programs starting at the same moment could each start a hub, each starting its own
  radio daemons and cluster connection. The hub now takes a lock first, and a second one exits straight away.
- **Contest databases you move or delete in the folder window are no longer listed.** "Open archive folder" opens a
  normal file window, and a database moved or deleted there stayed in the list. The lists are now rebuilt each time you
  come back to the program.

### New
- **J-Hub Setup is one screen.** The separate Station, Rig, Rotor, Amplifier, Antenna switch, Data, Modules and
  Satellites pages are now sections of a single **Setup** screen with its own menu on the left. It is the same drawer
  J-Learn uses for its chapters: it slides open when you point at it and has a **Pin** button. The menu is ordered the
  way you set a station up:
  - **Station**
  - **Radio:** Rig control, Rotor control, Amplifier, Antenna switch, Transmit & macros
  - **Data & spotting:** DX cluster & RBN, WSJT-X / digital, Callsign lookup, Satellites
  - **Logbook:** Log database & backup, Online upload, Export & Cabrillo
  - **System:** Modules, Remote sharing, J-Learn content

  The old Data page, which was one very long page, is split across these. Buttons elsewhere that used to jump to one of
  the old pages (J-Sat's satellite picker, J-Log's database tools) open the matching section.
- **Morse Trainer and Antenna Workshop have their own entries in the left dock.** They open inside J-Learn, as before,
  and can be switched off in **Setup ▸ Modules** like any other module.
- **A notice when the DX cluster is about to disconnect.** The hub shows a tray message when the last window closes
  ("Disconnecting from the DX cluster in 8 s"), and another when it has disconnected. No message is shown if the cluster
  was not connected, or on a desktop with no system tray.

### Changed
- **The dock is simpler.** The Dashboard link beside Setup and the Station-settings gear at the bottom are gone. The
  **J-Hub** entry at the top of the dock still opens the dashboard, and **Setup** opens the settings.

### Housekeeping
- The `CLAUDE.md` notes for each module now match the code (where settings are stored on disk, the update check,
  which classes do what), and `ars-fx/launch/README.md` no longer mentions a `build-release.sh --ars-fx` option that
  does not exist.
