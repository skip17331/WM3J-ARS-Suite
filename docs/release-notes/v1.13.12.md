## WM3J ARS Suite v1.13.12

A new **Log + Spot** button, and the dashboard's macro row stays on one line when the dashboard is tiled.

### New
- **Log + Spot.** A second save button next to **Log QSO** on the dashboard's New QSO card and on the contest page. It saves the QSO exactly as Log QSO does, then posts a spot for the station to the DX cluster.
  - On the dashboard the spot carries the frequency, the mode and your comment (cut to 30 characters).
  - The contest page has no frequency field, so the spot goes out on the rig's dial frequency, with the mode only.
  - The result shows in the status line: **✓ spotted CALL on the cluster**, or why nothing was sent. If the DX cluster is not connected, or the contest page has no rig frequency to use, the QSO is still saved.
  - It does nothing while you are editing a logged QSO, and pressing Enter in a field still logs without a spot.
  - On the contest page a dupe still asks first; choosing **Log the dupe** posts the spot too.
  - Remember that a spot goes out to the live cluster for everyone to see.

### Changed
- **Macro row on one line.** On the tiled dashboard the F-key buttons split across two rows. **Macros send as** and its CW / data and Voice ticks are now stacked into one cell, about the height of an F-key button, so the row fits again.

### Not yet tried
- The contest page's Log + Spot was built and compiled but not run against a live cluster.
- The macro row on the standalone J-Log page: only the dashboard's layout changed.
