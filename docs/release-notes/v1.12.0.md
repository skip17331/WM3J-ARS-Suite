## WM3J ARS Suite v1.12.0

The suite can now tell you when a new version is out and, on Windows and Linux, install it for you. The station-ID timer
is bigger and blinks when it is time to identify.

### New
- **Update check.** The app looks for a newer release about 15 seconds after it starts and then once a day. When there
  is one, a card appears in the bottom-right corner with **What's new**, **Skip this version** and **Later**. The check
  only asks GitHub for the latest release; nothing about you or your station is sent. Turn it off, see the version you
  are running, or check right now from **J-Hub ▸ Station ▸ Updates**.
- **Update now (Windows and Linux).** The card has an **Update now** button. The app downloads the new version, checks
  it against the checksum GitHub publishes for it, restarts, and keeps the old version as a `.bak` file. If the new
  version does not start, the old one is put back and the next start tells you what happened. It will not start while
  the transmitter is keyed, and it does not offer itself if the install folder is not writable by you; in that case the
  card says so and you update by hand. macOS does not have this yet: the card points you to the release page.
- **ID timer blinks.** From 2:00 left the timer turns yellow and blinks; at zero it shows ID NOW in red and keeps
  blinking. Click it after you identify to start the 10 minutes again.

### Changed
- **The ID timer is larger** and easier to read from across the room.
- **The theme button moved to J-Hub ▸ Station ▸ Appearance.** It is gone from the top bar of every module. It switches
  the colour scheme for the whole suite; per-module colour schemes can no longer be set.

### Upgrading
Versions before 1.12.0 do not have the update check, so install 1.12.0 the usual way (`git pull` and run the install
script, or download the jar for your system from the release page). From 1.12.0 on, updates can be applied from the app.
