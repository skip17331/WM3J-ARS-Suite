## WM3J ARS Suite v1.5.2

A patch release that makes the installer robust to version changes, brings every
module into version agreement, and folds in the UI facelift and scoring-engine
work that had landed on `main` since v1.5.1.

### Installer
- **Fixed: a version mismatch could block install entirely.** The bootstrap
  scripts (`install.sh`, `install.ps1`) hardcoded the installer jar filename, so
  a version bump left them pointing at a jar that no longer existed — the build
  succeeded but the launch failed. They now resolve `j-installer-*.jar` by glob.
- The installer now resolves each module's jar version-agnostically: if the
  manifest's pinned filename is absent it falls back to globbing the module's
  `target/` dir (preferring the runnable shaded jar). A module version bump can
  no longer strand its manifest entry as "missing build".

### Versioning
- The suite is now coherently versioned at **1.5.2** across every module,
  `j-log-engine`, the installer, and the manifest. **j-digi** stays on its
  separate **1.0.42** beta line by design.

### Other changes since v1.5.1
- Suite-wide UI facelift onto the slate palette across all desktop modules.
- Scoring logic extracted into the engine (`com.jlog.scoring`) as a pure,
  reusable `ContestScorer` — used by j-log and the standalone Plugin Builder.
- Expanded USER_GUIDE walkthroughs (J-Log, J-Map, and the remaining modules)
  with real screenshots, plus native aarch64 / Raspberry Pi build fixes.
- Fixed ARRL Rookie Roundup Cabrillo `CONTEST:` names.

### Note
- **j-digi remains decode-only on its 1.0.42 line.** Everything else is 1.5.2.
