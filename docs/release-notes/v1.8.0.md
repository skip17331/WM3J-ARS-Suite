## WM3J ARS Suite v1.8.0

The suite becomes one program with two ways to run it: a single **docked** window
(J-Hub plus every module), or each module **loose** in its own window sharing a
background hub. Everything is now coherently versioned at **1.8.0**.

### Docked or loose — your choice
- **Docked** (default): J-Hub and all modules in one window, navigated by the
  left dock — `ars-fx.sh`.
- **Loose**: any module in its own window — `ars-fx.sh --module log` (also map,
  sat, digi, vault, learn). Loose windows reach J-Hub / Station settings via the
  ⚙ gear in their top bar, with a "← Back to <module>" link.
- **Background hub**: a small headless process (`ars-fx.sh --hub`) owns the
  Hamlib daemons and live feeds (DX cluster, RBN, rig, rotor) and shares them on
  `ws://127.0.0.1:8090`; loose windows attach to it. It lives in the **system
  tray** (Open ▸ each module, Quit) and never opens a window of its own — the
  first module you launch brings it up automatically. Where no tray is available
  (e.g. GNOME/Wayland) it runs headless.

### Installer
- Installs the unified app: an **ARS Suite** (docked) shortcut, a per-module
  loose shortcut for J-Log / J-Map / J-Sat / J-Digi / J-Vault / J-Learn, and an
  **ARS Suite Hub** (tray) shortcut — all off the single `ars-fx` jar.
- Manifest entries gained an optional `args` field, threaded through the Linux
  `.desktop` Exec, the macOS `.app` wrapper, and the Windows `.lnk` Arguments, so
  one launcher serves the docked, loose, and hub shortcuts.
- **Prunes** stale shortcuts from the old per-program installer when it runs,
  while leaving unrelated `ars-*` apps (e.g. the standalone Plugin Builder) alone.

### Versioning
- The whole suite — every module, `j-log-engine`, `j-log-common`, the installer,
  and the manifest — is now at **1.8.0**. **j-digi joins the common version**
  (previously held on its separate 1.0.42 line).
