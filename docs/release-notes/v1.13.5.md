## WM3J ARS Suite v1.13.5

A small one: **Setup > Appearance > Interface size** now goes smaller as well as larger.

### New
- **Smaller interface sizes: 50%, 75%, 85% and 95%.** Interface size used to offer 100%, 150% and 200%; it now offers **50%, 75%, 85%, 95%, 100%, 150% and 200%**, for a small screen or a window that needs to show more at once. It scales text, panels, drawers and maps together, and, as before, takes effect the next time you start ARS Suite.
- There is still no 125%: on Windows the toolkit applies sizes above 100% only in 50% steps (a request for 125% behaves like 100%), whereas the sizes below 100% are honoured exactly, which is why the sizes below 100% could be added.

### Not yet tried
- Every screen at 50%: some text will be very small, and only the Setup page was looked at at 75% and 50%.
- macOS: only Windows and Linux have been run.

### Fixed
- **On Linux, the interface sizes came out far too small.** The size was handed to the toolkit as an absolute scale, replacing the one it picks for your screen (for example 2.0 on a 4K display), so 75% there drew at about 37% of normal. The size is now applied on top of the screen's own scale, so 75% on that display is 1.5. Windows is unchanged.
