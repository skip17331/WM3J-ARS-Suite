## WM3J ARS Suite v1.13.5

A small one: **Setup > Appearance > Interface size** now goes smaller as well as larger.

### New
- **75% and 50% interface sizes.** Interface size used to offer 100%, 150% and 200%; it now offers **50%, 75%, 100%, 150% and 200%**, for a small screen or a window that needs to show more at once. It scales text, panels, drawers and maps together, and, as before, takes effect the next time you start ARS Suite.
- There is still no 125%: on Windows the toolkit applies sizes above 100% only in 50% steps (a request for 125% behaves like 100%), whereas the sizes below 100% are honoured exactly, which is why 75% and 50% could be added.

### Not yet tried
- Every screen at 50%: some text will be very small, and only the Setup page was looked at at 75% and 50%.
- Linux and macOS: the new choices are handed to the toolkit the same way on every platform, but only Windows was run.
