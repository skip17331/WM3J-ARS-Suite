## WM3J ARS Suite v1.9.3

A small fix-up release for J-Digi, plus corrections to the hardware guide.

### Fixed
- **J-Digi now knows where your rig is tuned.** The built-in modem was never told the rig's frequency or mode, so
  J-Digi's *Rig freq* readout always showed "—", the band-plan caption stayed empty, and the decoders that use the dial
  frequency were given 0 Hz. The dial frequency and mode now come from the rig connection (the same one the rig panel
  uses) and update as you tune. While the rig is not connected the readout goes back to "—".
- **J-Digi's band-plan caption follows your IARU region.** It now uses the region set in **J-Hub ▸ Station** (and the
  US licence-class overlay for Region 2), instead of a separate setting inside the modem that nothing could change.

### Documentation
- **Hardware guide:** removed the instructions to open a web page at `localhost:8081`; rig and rotor setup is in
  **J-Hub ▸ Rig control** and **Rotor control**. The SignaLink and DigiRig sections now say to set **PTT method** to
  **VOX** there, because J-Digi's push-to-talk follows J-Hub's setting (default *CAT*) since v1.9.2.
- Module notes (`j-digi`, `ars-fx`) updated to match.

### Correction to the v1.9.2 notes
- The note that J-Digi's callsign "can show `NOCALL`" does not apply: nothing in the app used that value, and the
  unused code has been removed. The local CW skimmer still produces no spots, as noted for v1.9.2.

### Housekeeping
- Removed leftover code from the retired hub link in J-Digi's modem service.
