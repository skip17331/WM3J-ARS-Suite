## WM3J ARS Suite v1.12.2

J-Log can now print a QSL label for each contact as you save it. Label printing is a **beta** feature in this release.

### New
- **Print QSL label (beta).** The greyed-out placeholder in **J-Log** and **J-Log-Quick** is now a **Print QSL label**
  tick box. With it on, saving a new QSO prints a label with the callsign, UTC date and time, frequency, band, mode,
  RST sent and received, the other station's name and QTH, and "TNX QSO · 73 de" your callsign. Editing and updating an
  existing QSO does not print. The result (sent, or the reason it failed) shows under the tick box. The contest form
  does not print labels.
- **Setup ▸ Logbook ▸ Label printers.** Choose the printer model, the label stock loaded in it, where to send the job, and
  the number of copies, then press **Test print** to check it. Supported models:
  - **Brother:** QL-810, QL-810W, QL-800, QL-820NWB, QL-700 (DK-11209, 11201, 11208, 11202, 11204 and 22205 labels)
  - **DYMO:** LabelWriter 550, 550 Turbo, 5XL, 450 (30252, 30321, 30336, 30334 and 30256 labels; 4×6 on the 5XL)
  - **Zebra:** ZD421, ZD411, ZD621, ZD220, GK420d / GX420d (4×6 down to 2×1 inch labels)
  - **Rollo** X1040, and **Other** for any printer that has a system driver. Every model also accepts a custom size in mm.
- **Two ways to print.** Brother, DYMO, Rollo and other printers print through the system printer driver (CUPS on Linux
  and macOS, the print spooler on Windows). Zebra printers can instead take native ZPL, sent to the printer's network
  address (port 9100) or as a raw job to a print queue; the system driver also works.

### Beta notes
- Label printing has not yet been tried on every printer and label size. If a label comes out the wrong size or
  misaligned, check that the label stock in Setup matches the roll in the printer; some drivers ignore the page size the
  program asks for and use their own default. Please report the printer model and driver when something is off.

### Changed
- **Settings gear on every module.** The dock now has the Settings gear on every module screen, not only some of them.
- **Linux menu.** The installer groups all the suite's shortcuts in an **Amateur Radio** folder of the application
  menu on desktops that support it (Cinnamon, KDE, Xfce, MATE, LXQt). GNOME's app grid has no folders and lists them as
  before.

### Fixed
- **The installer's menu change did not take effect on a re-run.** `install.sh` reused an installer jar built before the
  change; it now rebuilds the installer whenever its sources are newer. The Cinnamon menu file is written to the folder
  Cinnamon actually reads.
- **No personal station defaults in shipped files.** The sample solo launch files, sample generator, trainer fallbacks
  and `INSTALL.md` use the `N0CALL` / `AA00` placeholders; the old sample station block overwrote the J-Hub station
  settings of anyone who ran it.
