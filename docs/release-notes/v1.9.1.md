## WM3J ARS Suite v1.9.1

A consolidation release. ARS Suite is now one app: the old standalone modules are
gone, the Morse Trainer, QSO phrase translator and bundled J-Learn content live
inside it, and macros are built from your station data. The whole suite —
every module, `j-log-engine`, `j-log-common`, the installer and the manifest — is
at **1.9.1**.

### New
- **Morse Trainer in J-Learn.** A "Morse Trainer" entry above the chapters opens
  the Letter trainer, Group trainer, QSO simulator, Sending practice and Settings.
  Keyboard, Arduino and Pi Zero keyers are supported. Settings and session logs
  are kept in `~/.j-learn/morse/`.
- **QSO phrase translator in J-Log.** A "Translator" button in J-Log and contest
  mode opens an editable, offline table of common QSO phrases (English, Spanish,
  German, Portuguese). "By country" follows the DXCC country of the call being
  logged; "Choose languages" shows the ones you tick. Each language now has its own
  pronunciation guide (German and Portuguese added; the guides are unreviewed
  approximations).
- **Macros built from station data.** 42 tags (`{MYCALL}`, `{NAME}`, `{QTH}`,
  `{GRID}`, `{RIG}`, `{PTT}`, `{ANT}` …) map to the J-Hub settings; `{CALL}` stays
  the worked station. Default macros are now templates instead of hard-coded
  values, with a "Rebuild from station data" button, new "My Info" and "Name/QTH?"
  defaults, and a live MACRO TAGS palette in J-Hub. A macro needing an empty
  setting is refused with a message naming it. J-Digi uses the same editable F1–F8
  macros as J-Log, with a DX call box.
- **Import ADIF** in J-Hub ▸ Data. Adds QSOs from an ADIF file to the normal log,
  skipping any already logged (same call, minute, band and mode). Reads UTF-8 or
  Windows-1252, fills a missing band from the frequency, and reports imported,
  skipped and unreadable counts.
- **J-Learn content is bundled and updatable.** The chapters ship in the jar and
  are copied to `~/.j-learn/content` on first open. J-Hub ▸ Data ▸ J-Learn content
  can update from a zip URL, local zip or folder (the old copy is kept as
  `content.backup`), restore the bundled copy, or open the folder.
- **App icons, native splash screen and tray icon** — windows carry the module
  icon, the splash shows at startup, and the tray uses the app mark.

### One shared band plan
J-Log, J-Log-Quick, J-Digi and J-Bridge now use a single data-driven band plan in
place of six hand-written tables that disagreed. Cluster spots no longer show
"OOB" on 60m, 2m and 70cm; 17m/12m log lookups and 70cm in J-Bridge are
corrected; 1.25m is in the Region 2 plan. The Station ▸ IARU region setting now
actually selects the plan, and J-Log and J-Log-Quick show a caption such as
"20m · CW segment" under the frequency.

### Fixed
- **Embedded J-Digi now starts audio.** It tried to connect to the retired central
  hub first, failed with "Hub connection failed" and never started capture. The
  embedded app now starts audio capture directly and reports audio failures in the
  decode log.
- Installers: `install.ps1` drops the retired j-hub steps and the stale
  `localhost:8081` ending; `bootstrap-mac.sh` builds through `install.sh` so Apple
  Silicon gets the right JavaFX profile and clears quarantine on the current
  bundle names.

### Housekeeping
- Removed the old standalone modules — j-hub, j-log, j-map, j-sat, j-vault, j-learn
  and morse-trainer — plus the external language packs, award-plugin data, unused
  screenshots and about 3,700 lines of library and app code nothing reached.
- J-Learn chapters moved to the repo-root `j-learn-content/` folder; Morse keyer
  hardware guides moved to `docs/morse-hardware`.
- `INSTALL.md` and `USER_GUIDE.md` rewritten for the unified app (INSTALL adds a
  no-build route using release jars). The outdated roadmap and plugin docs are
  removed.
