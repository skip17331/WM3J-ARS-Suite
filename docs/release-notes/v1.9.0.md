## WM3J ARS Suite v1.9.0

A big usability and operating release: the DX cluster is rebuilt, J-Log gets real
database management, J-Sat gets a proper satellite picker with live orbital data,
the F-key macros can now key the radio, and a long list of display problems on the
module tabs is fixed. The whole suite — every module, `j-log-engine`,
`j-log-common`, the installer and the manifest — is at **1.9.0**.

### Display and navigation fixes
- Frames that would not page down, or snapped back to the top right after a
  page-down, now behave. Lists that rebuild on every data update (J-Sat, the
  J-Hub / J-Map / J-Log cluster lists, J-Bridge decodes) keep your scroll position.
- Page Up / Page Down / Home / End now scroll the pane under the mouse.
- J-Map's controls panel scrolls instead of stretching the window and pushing the
  top bar and ticker off-screen; J-Digi's waterfall follows the window width and
  no longer clips the dock and right rail; J-Sat's satellite list and J-Bridge's
  decode table scroll.
- Buttons no longer collapse to "…" when the window is crowded, and the F1–F8
  macro buttons wrap onto a second row in a narrow column.
- **Tooltips** across the app: every button, the dock, drawer headers, switches,
  macro keys and spot rows, plus the full text of anything shortened with "…".

### J-Log: databases
- J-Log shows exactly which database and table it is writing to, with a
  **Database tools** shortcut to J-Hub ▸ Data.
- Switching to contest mode offers the **last contest** you used, then asks which
  database to log to: continue an existing one (each shown with its contest, start
  date and QSO count) or start a new one with an editable suggested name such as
  `NovSwpSSB2026.db`. A **Switch database** link is on the contest screen.
- J-Hub ▸ Data lists contest databases with **Archive** and **Restore**; archived
  files move to `~/.j-log/archive/<Contest>_<Year>/`.
- Fixed a long-standing bug where the SQLite driver treated `?busyTimeout=…` as
  part of the file name, creating stray files such as `j-log.db?busyTimeout=5000`.
  Data in such a file is adopted into the real one when that is empty.
- The small J-Hub logger is now **J-Log-Quick** (link: "Open J-Log"), and
  J-Log and J-Log-Quick have a greyed-out **Print QSL label** placeholder.

### J-Sat: satellite selection and orbital data
- New **J-Hub ▸ Satellites** page: download orbital data from Celestrak and AMSAT
  (daily auto-refresh, or on demand) and pick satellites from everything the data
  covers — searchable, filterable by "has a pass in the next 24 h above N°".
  A pick with no data is looked up on Celestrak by NORAD id.
- J-Sat tracks your picks (satellites without radio data still get position and
  passes), warns about picks with no orbital data, and points to the picker.
- Registry fixes: HO-113's NORAD id and three entries that had id 0.

### DX cluster and RBN
- One connection engine with one status model — **Disconnected / Connecting /
  Connected** — shown identically in every module. "Connected" now means the server
  answered after login (the old code marked itself connected as soon as the socket
  opened). The hub now honours the server and login set in J-Hub ▸ Data.
- A **Console** pop-up shows the raw feed and has a command line (with history and
  quick commands such as `SH/DX 20`, `SET/FT8`).
- **Stop** works while connecting or retrying, and a **retry limit** (default 5,
  0 = unlimited) is set in J-Hub ▸ Data.

### Propagation
- "Propagation" and "Band conditions" are merged into one drawer: MUF / FOT and the
  geomagnetic state, then one band table with HamQSL day/night ratings and a
  **DX-activity heat map** built from the last 30 minutes of cluster spots (hover a
  row for the CW / Phone / Digi split).

### Units
- **Metric or Standard (US)** in J-Hub ▸ Station: km / °C / km/h / hPa / m, or
  mi / °F / mph / inHg / ft, applied to J-Sat, the weather drawer, J-Bridge decode
  distance and the J-Map range rings.

### Macros and transmitting
- The F-keys follow the mode field, or a **Macros send as** choice (CW / data or
  Voice) next to the macro buttons in J-Log, J-Log-Quick and contest mode.
- Macros now **key the radio**: CW goes to the rig's own keyer through Hamlib;
  voice keys PTT, plays the file on the chosen output, and releases PTT; RTTY and
  PSK31 go to the J-Digi modem. A flashing red **TRANSMITTING** light shows in every
  module's top bar; **Esc** (or clicking the light) stops sending and drops PTT.
- Safety: nothing is sent unless the rig is connected; PTT is released on stop,
  error, window close or crash, and by a watchdog.
- J-Hub ▸ Data ▸ Transmit sets the CW speed, the voice output device, and a single
  **PTT delay** used both between keying and audio and between audio and un-keying.
- Not yet verified on a real radio — try a CW and a voice macro into a dummy load first.

### Versioning
- The whole suite moves from 1.8.0 to **1.9.0**.
