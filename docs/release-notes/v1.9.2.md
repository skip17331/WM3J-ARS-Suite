## WM3J ARS Suite v1.9.2

A tidy-up release. J-Digi's push-to-talk now follows your J-Hub rig settings, and the last leftovers of the old
standalone apps are gone, so J-Map is the only module that ships on its own. Little else changes on screen.

### Fixed
- **J-Digi's PTT now follows the J-Hub rig settings.** Before, the built-in modem read its own private
  preferences, which nothing in the app ever set, so Hamlib PTT ran on stale defaults. It now uses **J-Hub ▸
  Hardware ▸ Rig control**: *PTT method* VOX keys nothing, while CAT, RTS and DTR go through Hamlib (the rigctld
  daemon does the keying), and the *rigctld host / port* are used for both PTT and the Hamlib CW keyer. It applies
  when J-Digi starts and again as soon as you change one of those settings; a change made during a transmission takes
  effect afterwards.

### Behaviour changes to know about
- **A fresh install now starts J-Digi on Hamlib PTT**, matching J-Hub's default of *CAT*. It used to start on VOX.
  If you transmit without a rigctld running, J-Digi now reports an error instead of sending audio only. If you key
  through VOX or an audio interface, set *PTT method* to **VOX** in J-Hub.
- **RTS and DTR** are sent through Hamlib like CAT. They only key the rig if rigctld itself is started with that PTT
  type, which the app does not set up for you.
- **J-Digi's callsign** now comes only from its saved preference; it no longer arrives from a hub message, so it can
  show `NOCALL` until it is set.
- **The local CW skimmer no longer produces spots.** The detector still runs, but the part that turned scored
  callsigns into spots belonged to the retired hub link and has been removed.

### Housekeeping
- **J-Map is the only standalone module.** J-Digi and J-Bridge are libraries inside the main app, with no window,
  launcher or hub link of their own. Removed: their standalone windows and launcher scripts, `j-bridge-config.json`,
  the old hub clients, the hub-fed parts of J-Digi's modem service, and the classes and translation bundles only
  they used — about 7,000 lines in all. Loose mode and J-Sat solo are unchanged.
- J-Digi's test signals, generator scripts and play scripts moved to `tools/j-digi-test-signals/`; the AX.25 test
  reads its recordings from there. A stray scratch file in `j-digi/` was removed.
- Module docs rewritten to match the code: new `ars-fx/CLAUDE.md`, and rewritten `j-digi`, `j-bridge` and
  `j-log-engine` docs.
- The design handoff folder lost its early launcher prototypes and one-shot build prompts, and gained a
  `design/README.md` saying it is a historical reference.
