ARS SUITE PUNCH LIST
Updated 2026-11-19. Started from the 2026-11-17 review.

NOTE (2026-11-27, version 2.0): this list was written while contest logging was still part of the suite. Every
item that mentions the contest page, the contest network, N1MM+, Cabrillo, Super Check Partial or a QSO party is
about the contest program, which moved to ARS Contest (github.com/skip17331/WM3J-Contest-Suite) and is tracked in
that repository's TODO.md. The items are kept here as the record of what was done and checked; they are not open
work for the suite.

Sections
  1   Completed
  2   Completed, needs testing  (2a running app, 2b needs the rig, 2c needs accounts or
      servers, 2d other equipment)
  3   Known bugs
  4   Identified need, needs coding  (4a code, 4b QSO-party rules, 4c information from sponsors)
  5   Future (and decided against)

IDs
  Every item has a permanent ID: its section and a number (2a-3, 3-2, 4b-1). An ID never
  changes. When an item is finished it moves to section 1 keeping its ID, and the gap it
  leaves is not refilled, so "2a-3 is done" always means the same item. New items take the
  next unused number in their section.

  [!] = check before the next contest you enter.

4a-4    J-Digi screen CPU: profiled on Windows, half of J-Digi's CPU samples were adding one
        waterfall row (the whole image read back and rewritten with a pixel-format conversion each
        way, then the new row set one pixel at a time, each write re-checking the layout of the
        panes above). The waterfall now lives in its own buffer shown through a PixelBuffer: one
        copy and one update per row, and it no longer shows in the profile. Whole-process CPU is now
        about 6% against about 5% for a quiet screen (J-Vault), within run-to-run noise.
