# SWR — Standing Wave Ratio

> **Advanced callout convention:** sections or paragraphs intended for Extra-class / engineering depth are marked with a blockquote starting `> ⚙️ **Advanced —**`. Simple-mode renderers can hide these; advanced-mode renderers show them inline.

The standing-wave ratio is a single number that describes how well an antenna (or any load) is matched to its feedline. It's computed from the load impedance vs. the line's characteristic impedance, or from the forward and reflected power.

## Equations

From load impedance:

```
Γ = (Z_L − Z_0) / (Z_L + Z_0)            (reflection coefficient)
SWR = (1 + |Γ|) / (1 − |Γ|)
```

From forward and reflected power readings on a wattmeter:

```
|Γ| = √(P_r / P_f)
SWR = (1 + |Γ|) / (1 − |Γ|)
```

For a purely resistive load on a 50 Ω line (the simplest case):

```
SWR = R / Z_0   (when R > Z_0)
SWR = Z_0 / R   (when R < Z_0)
```

## Variables

| Symbol | Quantity | Units |
|--------|----------|-------|
| SWR | Standing-wave ratio (dimensionless) | — |
| Γ | Reflection coefficient (complex) | dimensionless |
| Z_L | Load impedance (typically antenna feed Z) | ohms |
| Z_0 | Feedline characteristic impedance | ohms (typically 50 Ω) |
| P_f | Forward power (watts measured by wattmeter) | W |
| P_r | Reflected power (watts measured by wattmeter) | W |

## Quick reference — what SWR means in dB

| SWR | Reflection (%) | Reflection (dB) | Mismatch loss | Comment |
|----:|----:|---:|---:|---------|
| 1.0:1 | 0% | −∞ | 0 dB | Perfect match — all power delivered |
| 1.5:1 | 4% | −14 dB | 0.18 dB | Excellent — ham work target |
| 2.0:1 | 11% | −9.5 dB | 0.51 dB | Good — most rigs run full power |
| 3.0:1 | 25% | −6 dB | 1.25 dB | Marginal — many rigs fold back |
| 5.0:1 | 44% | −3.5 dB | 2.55 dB | Poor — rig at risk |
| 10:1 | 67% | −1.7 dB | 4.81 dB | Bad — rig will fold back hard |

## Worked example — measure forward 100 W, reflected 4 W

```
|Γ| = √(4 / 100) = √0.04 = 0.2
SWR = (1 + 0.2) / (1 − 0.2)
    = 1.2 / 0.8
    = 1.5:1
```

Excellent match. The 4 W reflected reaches the rig and re-radiates back; over the cycle it adds and subtracts to give the standing-wave pattern that gives this measurement its name.

## Worked example — antenna shows R = 75 Ω, X = 0 on 50 Ω line

Pure resistance, R > Z_0:

```
SWR = R / Z_0 = 75 / 50 = 1.5:1
```

That's the SWR of an exactly-resonant 75 Ω folded dipole on 50 Ω coax — comfortably acceptable.

If the antenna were R = 25 Ω, X = 0 (R < Z_0):

```
SWR = Z_0 / R = 50 / 25 = 2.0:1
```

Same magnitude of "off by 25 Ω", but a higher SWR — this is the rule that "low impedance is worse than high impedance" for a given mismatch.

## Worked example — antenna at R = 65 Ω, X = +28 Ω

The full complex form:

```
Γ = (Z_L − Z_0) / (Z_L + Z_0)
  = ((65 + j28) − 50) / ((65 + j28) + 50)
  = (15 + j28) / (115 + j28)
  
|15 + j28| = √(225 + 784) = √1009 ≈ 31.8
|115 + j28| = √(13225 + 784) = √14009 ≈ 118.4
|Γ| = 31.8 / 118.4 ≈ 0.269

SWR = (1 + 0.269) / (1 − 0.269)
    = 1.269 / 0.731
    ≈ 1.74:1
```

Between the two simple cases above. The +28 Ω of inductive reactance worsens the SWR a touch even though \|Z\| ≈ 70 Ω is "close" to 50 Ω.

## Common mistakes

- **Reading SWR at the rig and assuming the antenna is fine.** A long lossy feedline lowers the SWR seen at the rig, hiding antenna problems. A 1:1 reading at the rig with 6 dB of cable loss could mean an open or short at the antenna. Measure at the antenna with a sweep, not at the rig.
- **Treating SWR as a power-loss number.** SWR alone doesn't tell you power lost. The mismatch loss column above shows real loss; for short lines and reasonable SWR the loss is tiny.
- **Confusing SWR with impedance.** A 1.5:1 SWR could be R = 33, R = 75, R = 50 with X = ±28, or many other combinations. SWR tells you how well-matched, not exactly *what* the impedance is.
- **Forgetting Z_0 isn't always 50 Ω.** Old TV coax (RG-59) is 75 Ω. A 50 Ω antenna on 75 Ω coax shows 1.5:1 SWR even though the antenna is "perfect" by ham conventions.

> ⚙️ **Advanced —** SWR varies along a feedline, but its magnitude is the same at every point on a lossless line. Lossy lines reduce the SWR-magnitude as you move *away* from the antenna toward the rig (because the reflected wave is attenuated more than the forward wave). This is why an SWR meter at the rig reads lower than a meter at the antenna for high-loss feedline scenarios.
